# Make-video-

این مخزن محل نگهداری ایده‌ها، پژوهش‌ها و متن‌های تولید محتوای ویدئویی است.

## پروژه‌ها

### [Apollyon](./Apollyon/README.md)
پروژه‌ای پژوهشی ـ محتوایی دربارهٔ نظام آپولونی، نظم و عقلانیت در تمدن، تقابل آپولونی/دیونیسوسی، اسطورهٔ آپولو، نماد گرگ و نسبت اسطوره با روان‌شناسی و تحول رفتار جمعی.

**اصل روش‌شناختی:** در همهٔ متن‌ها میان دادهٔ تاریخی، تفسیر نمادین و فرضیهٔ روان‌شناختی یا فرهنگی تمایز گذاشته می‌شود. شباهت نمادها به‌تنهایی اثبات‌کنندهٔ رابطهٔ تاریخی یا اقتباس مستقیم نیست.
