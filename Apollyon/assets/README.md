# Apollyon — Image assets

This folder is reserved for the original images used in the Apollyon research and episode materials.

**Transfer status (2026-11-03):** The GitHub connection can create and edit text files, but the original image files embedded in earlier chat messages are not exposed here as downloadable file objects. They have therefore **not** been copied into this repository. No substitute images have been silently presented as the originals.

When the original image files are available, add them here and record for each:
- filename and a short description;
- original source or creator;
- source URL, if applicable;
- license / reuse terms;
- which section or episode uses it.

Suggested organization:
- `Apollyon/assets/apollo/`
- `Apollyon/assets/dionysus/`
- `Apollyon/assets/ancient-art/`
- `Apollyon/assets/diagrams/`

For public-domain or openly licensed images, preserve attribution and license details. Do not upload copyrighted images unless you have permission or a valid basis to use them.
